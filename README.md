### Deployment Prerequisites
1. Download your EC2 key pair (`.pem` file) from AWS.
2. Move it to your local SSH directory and restrict permissions:
   ```bash
   mv ~/Downloads/your-key.pem ~/.ssh/
   chmod 400 ~/.ssh/your-key.pem

Deploy to a server using `./deploy/configure_app.sh yoururl`

### Fandom / Leaguepedia API Credentials Setup
1. Log in to your Leaguepedia (Fandom) account.
2. Go to Special:BotPasswords (`https://lol.fandom.com/wiki/Special:BotPasswords`).
3. Click Create, enter a Bot Name (e.g., `FantasyLoLBot`), and select High-volume editing (bot) or Basic rights.
4. Save the generated Bot Password string.
5. Create a `.env` file in the root of your project directory based on `.env.example`:
```
# Server Configuration
PORT=8080
INGEST_REMOTE=true

# Fandom Credentials
FANDOM_USERNAME=YourMainAccountName
FANDOM_BOT_PASS=YourMainAccountName@BotName12345abcdef
```

* `FANDOM_USERNAME`: Set to only your primary Fandom account name (e.g., `MyUser`).
* `FANDOM_BOT_PASS`: Set to the full string generated by Fandom (e.g., `MyUser@FantasyLoLBot12345abcdef`).

### Setting Up Automated Data Ingestion (EC2 Cron Job)
To automatically pull recent match data and pro player stats daily from Leaguepedia:

1. SSH into your EC2 instance:
```bash
ssh -i ~/.ssh/your-key.pem ubuntu@your-ec2-ip
```

2. Make sure the ingestion script is executable:
```bash
chmod +x ~/fantasylol/ingest.sh
```

3. Open the crontab editor:
```bash
crontab -e
```
*If prompted to select an editor, press 1 to choose `/bin/nano.`*

4. Add the daily schedule rule:
Scroll to the bottom of the file and paste the following line (adjusting paths if your project directory differs):
```
0 3 * * * /home/ubuntu/fantasylol/ingest.sh >> /home/ubuntu/fantasylol/data/ingest.log 2>&1
```
This schedules ingest.sh to run every day at 3:00 AM UTC and logs output to `data/ingest.log`.

5. Save and exit:
* Press `Ctrl + O`, then `Enter` to write the file.
* Press `Ctrl + X` to exit `nano`.

6. Verify the cron schedule:
```bash
crontab -l
```

### Data ingestion
#### Manual ingestion
While server is running, use curl
```
curl -X POST http://localhost:8080/admin/stats/update
```
Replace localhost with live URL if running on a server

#### Automatic ingestion
In `.env` set `INGEST_REMOTE=` to true for automatic ingestion. This will run at 3am UTC
while server is running.

*This requires that you have set up automated data ingestion on the server using the
instructions above under "Setting Up Automated Data Ingestion (EC2 Cron Job)"*
